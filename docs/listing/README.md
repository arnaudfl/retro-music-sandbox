# 🎶 CPC Music Listings Archive

This folder contains manually transcribed Locomotive BASIC music listings
from classic Amstrad CPC magazines (CPC, Amstrad 100%, Micro News, etc.).

Each listing includes:

- Original source & author  
- High-resolution scan (when available)  
- Clean Markdown transcription  
- DATA blocks preserved  
- Notes and corrections  
- Optional downloadable `.BAS` or `.DSK`
